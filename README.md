# e-Bliss ClinicCare Prescription Demo

A static HTML/CSS/JavaScript prototype inspired by the ClinicCare sample layout. It is intended for requirement-gathering only.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in Chrome or Edge.
3. Search sample medicines, add/remove medicines, edit dosage/duration, change instructions, and click **Save & Print Prescription**.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `ebliss-clinic-prescription-demo`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Open the URL GitHub Pages provides.

## Important
- This is a front-end demo only. Save is a session-only confirmation; there is no database or server.
- All clinic, doctor, patient, and medicine information is illustrative. Replace clinic details only after the doctor confirms them.
- Do not enter or publish real patient information in this public demo.
- The sample medicine list is not a validated prescribing database. Medicine choices, strengths, dosage, and instructions must be checked and approved by a qualified clinician.
- This is not ready for real clinical use.
